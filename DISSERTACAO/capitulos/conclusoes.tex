Este trabalho apresentou o desenvolvimento de uma metodologia de cálculo da influência da folga de \textit{backlash} dinâmico no comportamento vibratório de um conjunto de rotores. Tal fenômeno tem sua importância respaldada na vasta utilização de trens de engrenagens em diversos setores da engenharia mecânica. 
Assim, este efeito é importante para o desenvolvimento de modelos mais representativos proporcionando uma análise confiável da dinâmica de rotação de um trem engrenado.
%Assim, um estudo eficaz sobre este efeito torna-se de suma importância para o desenvolvimento de modelos mais precisos, representativos e que contenham funcionalidades que colaborem para uma análise confiável da dinâmica de rotação de um trem engrenado.

Nesse sentido, este trabalho cumpriu o objetivo de desenvolver uma implementação numérica para o cálculo da folga dinâmica de \textit{backlash}. Tal modelagem, feita com base no trabalho anterior de \citeonline{yi2019}, foi validada de maneira coerente com o encontrado na literatura. Além disso, foi possível observar ainda a interação entre os efeitos de deslocamentos paralelos e perpendiculares à Linha de Ação das engrenagens. O desenvolvimento de um modelo analítico simplificado permitiu verificar a validade do modelo implementado, considerando os avanços em relação à referência base.

Ademais, o modelo base teve sua formulação expandida para contemplar, também, engrenagens de dentes helicoidais, a partir do desenvolvimento feito por \citeonline{kubur2004}. A metodologia de suavização da função de \textit{backlash} dinâmico proposta por \citeonline{walha2006} também foi adicionada à implementação feita. O modelo desenvolvido e implementado, associado com essas ferramentas, foi aplicado em um caso de modelagem real de um conjunto engrenado utilizado em plantas industriais da Petrobras, onde foi possível observar o funcionamento prático do código testado.

Apesar dos resultados promissores, o estudo apresenta algumas limitações. O modelo foi restrito à análise de um par de engrenagens cilíndricas de dentes retos e helicoidais, não contemplando outras geometrias. Além disso, devido à complexidade das equações não lineares de movimento, a execução computacional pode ser demorada.
Ainda assim, a formulação proposta apresenta forte potencial de integração com os gêmeos digitais (\textit{digital twins}). Nesse cenário, o modelo pode atuar como referência para a verificação periódica do sistema rotativo real, monitorando continuamente o equipamento para apontar alterações físicas, falhas ou desgastes ao longo de sua vida útil.
%Ainda assim, a formulação proposta apresenta um forte potencial para ser integrada ao conceito de gêmeos digitais (\textit{digital twins}). Nesse cenário, o modelo pode servir como uma referência para a verificação periódica do sistema rotativo real, atuando no monitoramento contínuo para indicar possíveis alterações físicas, falhas ou degradações ao longo da vida útil do equipamento.

Em suma, o desenvolvimento realizado neste trabalho contribui para o avanço e a pesquisa na área de sistemas engrenados, através do desenvolvimento de um modelo representativo para o \textit{backlash} dinâmico. Além disso, o modelo implementado mostra-se como uma solução confiável por estar em associação com o \textit{Rotordynamic Open-Source Software} (ROSS), código computacional já testado nos mais diferentes cenários de aplicação industrial.


\section{Sugestões de trabalhos futuros}

Como sugestões de trabalhos futuros para continuação desta dissertação pode-se citar:

\begin{itemize}
	\item Desenvolvimento de bancada experimental para validação das simulações computacionais;
	\item Utilização da metodologia proposta para a análise de vida de engrenagens; 
	\item Adequação da metodologia para trens com mais de duas engrenagens;
	\item Desenvolvimento de metodologia para engrenagens planetárias;
	\item Desenvolvimento de metodologia para engrenagens cônicas.
\end{itemize}
