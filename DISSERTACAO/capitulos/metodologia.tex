\thispagestyle{empty}


Neste trabalho a modelagem da folga de \textit{backlash}, proposta por \citeonline{yi2019}, foi implementada em um código \textit{Python} em associação com a biblioteca \textit{ROSS}. Neste sentido, adaptações deste modelo forma propostas para a plena integração coma  biblioteca. Além disso, um modelo analítico simplificado foi proposto para facilitar a compreensão do problema. Tal modelo visa a identificação das frequências naturais compreensão do comportamento dinâmico de um sistema simples de duas engrenagens.
